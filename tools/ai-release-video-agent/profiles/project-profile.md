# Project Profile

## Project

Zhiyu is a personal AI workspace for memory, workshops, integrations, and agent-driven workflows.

## Audience

- Individual builders who want an AI workspace they can control.
- Power users who care about memory, automation, and connected tools.
- Developers who want an extensible local-first companion.

## Brand Voice

Clear, practical, slightly warm, and focused on what the update lets users do.

## Video Rules

- Prefer real product screenshots and recordings over fully synthetic footage.
- Explain technical changes as user benefits.
- Keep each release video short: 20-45 seconds.
- Do not claim features that are not supported by the Git changes.
