# Keep memory protocol global and recall profiles Work-scoped

Zhiyu uses one stable, domain-neutral Memory Usage Contract for all agents. Domain vocabulary and ranking boosts live in versioned Recall Profiles bound to individual Works, while a Memory Quality Work may observe feedback and propose reviewed changes but may not rewrite the Skill, global policy, access grants, or another Work's memory automatically. This prevents frequent memory content from turning into global domain bias while preserving task-specific retrieval quality.
