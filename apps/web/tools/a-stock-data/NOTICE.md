a-stock-data adapter
====================

This adapter is inspired by the public project:

- Repository: https://github.com/simonlin1212/a-stock-data
- Author: Simon Lin
- License: Apache License 2.0

The original project is distributed as a Markdown skill with embedded Python
endpoint examples. This directory contains a controlled adapter for Zhiyu
workshop agents. It exposes a fixed JSON action surface instead of arbitrary
Python execution.
